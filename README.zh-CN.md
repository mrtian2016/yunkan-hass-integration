# 云瞰 Home Assistant 集成

[English](README.md) | **中文**

一个用于自托管**云瞰**摄像头服务器（[yun-kan.com](https://yun-kan.com)）的
[Home Assistant](https://www.home-assistant.io/) 自定义集成。

它是一个薄客户端：通过云瞰服务器常规的 REST 与事件（SSE）接口与其通信，把服务器
的能力映射成 Home Assistant 原生实体、媒体浏览器和若干服务。所有录制、检测和账号
逻辑都留在服务器端——集成本身只保存连接信息，不存任何业务数据。

> 想要零配置接入？云瞰也能通过 MQTT 发现把摄像头推送到 Home Assistant。本集成是
> 更完整、面向 Pro 的另一条路线，且**不需要** MQTT broker。

## 功能

- **摄像头**：原生 WebRTC（低延迟，HLS 兜底）+ JPEG 快照。接入后即可使用 HA 的整个
  摄像头生态：画面预览卡、区域仪表盘、导出到 HomeKit、`camera.snapshot` 等。
- **检测占位传感器**（每相机）：人、车、动物、包裹、人脸、跌倒、婴儿哭声、手势。
  事件触发瞬间点亮（把识别到的姓名 / 车牌 / 手势作为属性带上），物体在场期间保持
  点亮（实时跟踪；手势为瞬时脉冲），另有通用的 **移动侦测** 和 **在线** 传感器。
- **对象计数传感器**（每相机实时人 / 车 / 动物 / 包裹数量）以及 **识别人名** /
  **识别车牌** / **识别手势** 传感器。
- **只为真正启用的检测项创建实体**：关掉人脸识别的相机就不会有人脸传感器、
  「最新人脸」图片和「识别人名」传感器。重新打开（逐相机或服务器级）后，实体
  在一个轮询周期内自动回来——实体 ID 不变，改过的名称 / 区域 / 图标也保留，
  无需重载集成。移动侦测、在线、摄像头和各开关始终存在。
- **最近事件图片**（每相机）+ **每类目最新快照**（带检测框），方便做富通知。
- **最近事件** 时间戳传感器，把事件类目、姓名、车牌、摘要作为属性带上。
- **开关**（每相机）：AI 检测、录像、逐特性检测开关（物体 / 声音 / 人脸 / 车牌 /
  姿态 / 手势 / 包裹）以及 PTZ 自动追踪。
- **服务器级检测开关**（挂在云瞰服务器设备上）：每个检测特性一个总开关（物体 /
  声音 / 人脸 / 车牌 / 姿态 / 手势 / 包裹）外加 **移动侦测**，与 Web 管理台检测页
  同一套控件。这里关掉的特性对所有相机都关；每相机开关在其之下。移动侦测只有服务器
  级（逐相机的移动是靠灵敏度 / 区域调节，而不是开关）。
- **设备页上的一键控件**：每相机一个 **刷新快照** 按钮；云台相机额外有
  **上 / 下 / 左 / 右** 和 **停止** 按钮（按方向键开始持续移动，按停止——或
  等 8 秒安全定时器——结束）、一个列出该相机自有预置位的 **云台预置位** 下拉框，
  以及一个 **喊话内容** 输入框配 **语音喊话** 按钮。再复杂的自由输入仍走服务。
- **鸟瞰**（birdseye）总览摄像头（当服务器启用时）。
- **媒体浏览器**：按天翻录像、看最近事件、浏览快照画廊（带缩略图），全部经由
  Home Assistant 自身的鉴权代理。
- **设备触发器**——“检测到人”“检测到车辆”等——用于在界面上搭建自动化，另附一个
  开箱即用的通知蓝图。
- **设备动作**——转动云台、转到预置位、语音喊话、抓拍、导出片段——在自动化编辑器
  的「然后做」里按摄像头设备直接选。
- **服务**：`yunkan.ptz`（方向或预置位）、`yunkan.tts_broadcast`（Pro）、
  `yunkan.snapshot`、`yunkan.export`（区间导出，原速或缩时）。
- **服务器更新** 实体，反映服务器端可用的新版本。
- **侧边栏面板**（可选）：把完整的云瞰网页控制台嵌进 Home Assistant 侧边栏——见
  [侧边栏面板](#侧边栏面板内嵌网页控制台)。

## 前置要求

- Home Assistant **2024.12** 或更新。原生 WebRTC 摄像头是 2024.11 起有的，
  但本集成的选项对话框依赖 2024.12 才下放到基类的配置项引用。
- 一台可访问的云瞰服务器。填它的主入口地址（nginx 入口，通常端口 `23406`），例如
  `http://192.168.1.10:23406`——**不要**填内部端口。
- 一个云瞰账号。PTZ、检测开关和语音喊话需要 **管理员** 账号；查看和浏览用任意账号
  即可。

## 安装

### HACS（推荐）

[![在 HACS 中打开](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=mrtian2016&repository=yunkan-hass-integration&category=integration)

Yunkan 还没上架 HACS 默认商店，所以以**自定义仓库**方式安装——上方按钮会帮你完成：
点击即可在 HACS 中打开本仓库，安装 **Yunkan** 后重启 Home Assistant。或手动添加：

1. 在 HACS 里点右上角三点菜单 →「自定义仓库」，填入
   `https://github.com/mrtian2016/yunkan-hass-integration`，类别选 **Integration**。
2. 搜索 **Yunkan** 安装，然后重启 Home Assistant。
3. 进入 **设置 → 设备与服务 → 添加集成 → Yunkan**，填入服务器地址、用户名和密码。

### 手动安装

把 `custom_components/yunkan` 复制到 Home Assistant 的 `config/custom_components`
目录，然后重启。

## 直播与 WebRTC 可达性

直播优先走 WebRTC，无法建立时自动回退到 HLS。要让 WebRTC 连上，运行 Home Assistant
的机器必须能访问到云瞰服务器主机上的媒体面（UDP/TCP 端口 `23515`）：

- 把云瞰作为 Home Assistant 加载项运行（host 网络）——开箱即可达。
- 远程 / 反向代理部署——转发 UDP+TCP `23515`，并设置服务器的公网地址，让它对外通告
  一个可达的候选地址。反代清单见云瞰的 Home Assistant 文档。

仪表盘里的直播是 WebRTC。快照、录像、投屏和静态预览走 HLS，无论如何都能用；如果
WebRTC 媒体面不可达，直播卡片会报错，所以请确保 `23515` 端口可达。

## 侧边栏面板（内嵌网页控制台）

在选项里（设置 → 设备与服务 → Yunkan → 配置）可以把完整的云瞰网页控制台加进
Home Assistant 侧边栏。面板是一个直接指向云瞰服务器的 iframe——Home Assistant
**不**代理这部分流量——因此有几条前提：

- **浏览器必须能直接访问云瞰地址**（同一局域网，或云瞰自己的公网 HTTPS 访问）。
  面板本身不经过 Nabu Casa 远程通道；你在哪里打开 HA，云瞰就要在哪里可达。
- **HA 走 HTTPS 时，面板地址也必须是 HTTPS。** 浏览器会把 HTTPS 页面里的
  HTTP iframe 当混合内容拦截。云瞰内置公网 HTTPS 访问（单端口直连 + 自动
  Let's Encrypt 证书），把那个地址填进「面板使用的控制台地址」即可。
- **在面板里登录需要服务端开关——集成会替你打开。** 勾选面板选项时，集成自动在
  服务器上开启「允许被 Home Assistant 内嵌」（要求集成配置的是管理员账号）。
  账号不是管理员、或服务器版本太老没有该设置时，会弹出一条修复建议告诉你怎么办
  ——也随时可以在网页控制台手动开启（设置 → 远程实时直播 → 高级）。面板选项开着
  期间，集成会保持该开关开启（重载/重启时会重新确认）；它从不替你关闭——想彻底
  关掉，请先取消面板选项，再到网页控制台里关闭开关。面板内登录
  仅在面板地址为 HTTPS 时有效——纯 HTTP 下现代浏览器无论如何都不会在 iframe 里
  接受会话 cookie。
- **对讲请用完整标签页。** 侧边栏 iframe 拿不到麦克风权限。整体拦截第三方 cookie
  的浏览器（Safari、Chrome 无痕模式）也无法在内嵌页里登录——这类环境请新开标签页
  打开控制台。

「面板使用的控制台地址」留空 = 复用连接地址；当浏览器应该用另一个地址打开时才填
（典型场景：集成走局域网地址连接，面板用你的 HTTPS 域名）。

## 选项

设置 → 设备与服务 → 云瞰 → **配置**。保存后立即生效（集成会自行重载）。

| 选项 | 默认 | 作用 |
|---|---|---|
| 在事件图片上画检测框 | 开 | 由服务器把检测框画到「最近事件」/ 各类目最新快照上，和事件中心一致。 |
| 把事件图片裁到检测目标附近 | 关 | 把同一批图片放大到检测目标并留一点余量，做通知预览很合适。 |
| 在侧边栏显示云瞰网页控制台 | 关 | 见 [侧边栏面板](#侧边栏面板内嵌网页控制台)。 |
| 侧边栏面板标题 | 云瞰 | 侧边栏里显示的名字。 |
| 面板使用的控制台地址 | *（连接地址）* | 当浏览器打开面板要用另一个地址时填，留空则复用集成的连接地址。 |

## 免费档 vs Pro

摄像头、快照、事件、传感器、媒体浏览器和 PTZ 在任意云瞰服务器上都能用。**AI 检测** 和
**语音喊话** 是 Pro 功能；在免费档服务器上，这些操作会弹出一条修复提示（repair issue）
说明需要升级，而不是静默失败。

## 与 MQTT 发现共存

如果你同时用了云瞰的 MQTT 发现，会得到两套摄像头实体。本集成使用不同的实体 ID，不会
冲突，但你可能想禁用 MQTT 提供的摄像头 / 事件实体以避免重复。两条路线彼此独立，谁也
不会自动禁用对方。

## 服务

| 服务 | 说明 | 档位 |
|---|---|---|
| `yunkan.ptz` | 控制云台摄像头；持续移动会在短暂时长后自动停止 | 免费（管理员） |
| `yunkan.tts_broadcast` | 通过摄像头扬声器播报一段文字 | Pro（管理员） |
| `yunkan.snapshot` | 抓取一张新快照保存到文件 | 免费 |
| `yunkan.export` | 把某个时间区间的录像导出成可下载片段 | 免费 |

示例：

```yaml
service: yunkan.ptz
target:
  entity_id: camera.front_door
data:
  direction: left
  speed: 0.5
  duration: 1
```

### 设备动作

同样这几个动作也能在自动化编辑器里按摄像头设备直接选（「然后做」→ 选设备）：

| 设备动作 | 背后的服务 |
|---|---|
| 转动云台 | `yunkan.ptz`（方向、速度、时长） |
| 转到预置位 | `yunkan.ptz`（预置位、速度） |
| 语音喊话 | `yunkan.tts_broadcast`（内容、音色、语速、音调） |
| 抓一张快照 | `yunkan.snapshot`（文件名） |
| 导出片段 | `yunkan.export`（开始、结束、播放倍速） |

云台相关的动作只在支持云台的相机上出现，语音喊话只在带扬声器的相机上出现。

## 自动化与通知

每个摄像头设备都暴露了 **设备触发器**（“检测到人”“检测到车辆”……）——新建自动化时
选一个并指定摄像头即可。触发数据里会带上识别到的姓名 / 车牌。

集成附带一个开箱即用的通知蓝图。它不会自动安装，所以需要用 URL 导入一次（My Home
Assistant → 蓝图 → 导入，或 **设置 → 自动化与场景 → 蓝图 → 导入蓝图**），使用本仓库
中 `blueprints/automation/yunkan/camera_notification.yaml` 的 raw URL。当所选摄像头
检测到东西时，它会发送一条带快照的移动端通知。

## 故障排查

- **“服务器尚未完成初始化”**——先打开云瞰 Web 界面创建一个管理员账号，再添加集成。
- **直播黑屏但快照正常**——WebRTC 没能连上 `23515` 端口的媒体面。检查端口转发 /
  服务器公网地址。
- **检测开关或语音喊话失败**——确认你的账号是管理员，且服务器是 Pro 档。
- **某个逐特性检测开关（人脸 / 车牌 …）打不开**——每*相机*的开关是叠加在服务器级设置
  之上的覆盖。你可以给某一台相机把某特性*关掉*，但服务器级已禁用的特性无法在单相机上
  启用。请先用云瞰服务器设备上对应的 **服务器级** 开关（或在 Web 管理台）打开它，再
  逐相机调整。

上报问题时，请从集成的设备页抓取诊断信息（凭据和流密钥已脱敏）。
